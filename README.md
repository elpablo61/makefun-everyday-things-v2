# Everyday Things, Two Lines, Longer Run

> An alarm clock is a tiny rooster trapped in a box that crows with a bell instead of a beak.
> It maps a loud call that wakes you at a set time, but leaves out that a real rooster wakes with the sun and never needs batteries or a snooze button.

A two-line explanation of an everyday thing for a 10-year-old: line 1 explains an alarm clock through one concrete, surprising analogy, and line 2 honestly says what that analogy maps and what it leaves out.
